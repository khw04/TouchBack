# TouchBack

기존 인덕션을 개조하지 않고 사용자의 조작 결과를 확인해 주는 접근성 AI Agent 프로젝트.
사용자가 인덕션을 직접 조작하며, Agent는 목표 해석·안내·관측 검증·오류 교정과 재검증을 담당한다.

## 원안과 첫 구현

P0는 개발 시작 단계이며 제안서 전체 완료를 뜻하지 않는다. 재동기화·재보정·잔열·2화구·고객 검증 등의 [본선 원안 목표](docs/본선원안목표.md)를 별도 추적한다.

## 현재 상태

2026-10-10 기준 화면과 실행 API 클라이언트, UI fixture가 구현되어 있다. `/api/runs` 백엔드, Agent, 실측 결과는 아직 통합되지 않았다.
센서·부품은 [확정 견적 구성](docs/센서선정.md)대로 구매하기로 했다. 배송·수령과 인덕션 확보는 별도 확인이 필요하다. 멘토 피드백에 따라 Agent/Skill 개발과 판단·재계획 Demo를 우선한다. 첫 구현은 Python/FastAPI, 정적 웹 화면, ESP32 Arduino와 USB 통신을 기본값으로 사용한다.
소프트웨어는 모의 입력으로 개발하고 전자팀의 실측이 준비되면 같은 인터페이스의 실제 입력으로 연결한다.

## 이름으로 시작하기

AI에 “나는 권희원이야. 내 다음 작업 진행해”처럼 입력한다.
[역할분담](docs/역할분담.md) → [작업현황](docs/작업현황.md) → [구현기준](docs/구현기준.md)에 따라 실행 가능한 첫 티켓부터 시작한다.

모의 입력 Demo와 실제 센서 Demo는 명확히 표시한다. 완료한 기능은 근거와 함께 기록한다.

## 화면 예시 실행

Python 3.11 이상이 있는 새 환경에서 저장소 루트에서 실행한다.

```powershell
python -m http.server 8765
```

`http://127.0.0.1:8765/frontend/?fixture=1`을 연다. 이 모드는 화면·음성·입력 흐름을 확인하는 **UI fixture**이며 서버 판정이나 인덕션 동작을 수행하지 않는다. 실행 후 `조작 완료 알림`을 눌러도 결과는 `uncertain`이다. 브라우저 음성 지원이 없으면 화면의 안내 문구를 읽을 수 있다.

화면의 ‘지금 할 일’은 단계별 행동을 크게 보여준다. 필요하면 ‘큰 글씨 켜기’를 누르고, 화면 낭독기와 소리가 겹치면 ‘새 안내 자동 읽기’를 해제한다. 자동 읽기를 꺼도 안내 텍스트와 ‘안내 다시 듣기’는 사용할 수 있다.

계약에 맞는 백엔드가 준비되면 서버가 `frontend/`를 같은 출처에서 제공하도록 하고 `/frontend/`를 연다. 화면은 [실행계약 v0.2](docs/실행계약.md)의 `/api/runs`만 호출한다. [Demo 실행 순서](docs/Demo실행.md), [검증 현황](docs/검증결과.md)을 따른다. 다른 출처의 개발 서버와 연결할 때는 `?api=http://127.0.0.1:8000`을 쓰며 백엔드 CORS 설정이 필요하다.

```powershell
node --test tests/integration/frontend.test.mjs
```

Node.js 20 이상에서 프런트 계약 검사를 실행한다.

## 제출물 준비

- 발표자료: 고객 문제, Agent 흐름, 구현 범위, 실측 근거, 한계를 각 담당자 증거로 갱신한다.
- 영상: 실제 실행의 입력→안내→Tool/관측→판정/복구를 연속 촬영하고 `source`와 `execution_mode`를 함께 보여준다. UI fixture 영상은 실제 Agent 시연으로 사용하지 않는다.
- 소스 ZIP: README, `frontend/`, 백엔드/검증 코드, 실제 구현한 `skills/<name>/SKILL.md`, 예제 설정, 재현 가능한 실행 방법을 포함한다. 비밀키·캐시는 제외한다.

GitHub 원격: https://github.com/khw04/TouchBack (공개). main은 팀원 최소 1명 승인과 최신 변경 재승인을 요구하며 관리자에게도 적용한다. 보호 설정 확인은 docs/협업시작.md를 따른다. 실행 방법은 코드가 생긴 뒤 실제 확인한 절차로 추가한다.

사용자의 명시 승인으로 원본 PDF 두 개를 pdf/에 포함했다. 문서에서 해당 원문을 참조하며 원본은 수정하지 않는다.

## API 설정 준비

실제 모델과 테스트용 Mock 센서를 연결해 먼저 개발한다. 초기 제공자/모델 기본값은 OpenAI / gpt-6-luna이며 최종 성능 검증 완료를 뜻하지 않는다.
[.env.example](.env.example)은 설정 형식만 제공한다. 실행 코드가 구현되면 백엔드가 로컬 .env를 읽고 키 누락/호출 실패를 명시적으로 처리하도록 한다. 현재 실행 명령은 아직 없다.
지원받은 API 예산은 팀 전체 개발과 Agent 실행을 합쳐 20만 원이며, [Agent실행](docs/Agent실행.md)에 설정·검증·사용량 기준을 정리했다.
