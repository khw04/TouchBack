# TouchBack

기존 인덕션을 개조하지 않고 사용자의 조작 결과를 확인해 주는 접근성 AI Agent 프로젝트.
사용자가 인덕션을 직접 조작하며, Agent는 목표 해석·안내·관측 검증·오류 교정과 재검증을 담당한다.

## 원안과 첫 구현

P0는 개발 시작 단계이며 제안서 전체 완료를 뜻하지 않는다. 재동기화·재보정·잔열·2화구·고객 검증 등의 [본선 원안 목표](docs/본선원안목표.md)를 별도 추적한다.

## 현재 상태

2026-10-13, main `35aa58a` 기준: 공통 계약·Mock 관측·의도 검증(PR #5~7), Serial/Replay 어댑터(#8), Mock 보정·상태 복구(#9), 화면(#10), 실행 API·설정/Tool/provider(#11), Agent 관측·검증·복구 코드(#12), Windows 모듈 응답/캐시 수정(#13)이 병합됐다.

실행 API와 화면은 로컬에서 사용할 수 있다. 현재 API는 `backend_stub`이며 실제 LLM 호출과 관측 어댑터의 운영 연결은 C-YD-04에 남아 있다. Mock 검증 완료를 실제 Agent·인덕션 시연 완료로 합산하지 않는다. 티켓별 근거와 남은 작업은 [작업현황](docs/작업현황.md)을 따른다.

사용자는 견적서 구성의 부품과 인덕션을 구매했다고 알려왔다. 수령·설치·펌웨어 전송·실측 근거는 별도로 확인한다. Agent/Skill을 우선 개발하고 실제 센서 자료가 준비되면 같은 계약으로 연결한다.

## 로컬 실행과 화면 주소

Python 3.12를 사용하고 저장소 루트에서 실행한다. 최초 설치 방법은 [백엔드 README](backend/README.md)를 따른다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-dev.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

| 주소 | 용도 | 현재 예상 동작 |
|---|---|---|
| `http://127.0.0.1:8000/` | 백엔드 API를 쓰는 기본 화면 | 실행 생성·조회·조작 완료 알림·취소. 현재 응답은 `backend_stub` |
| `http://127.0.0.1:8000/?fixture=1` | 화면 연습 | 브라우저의 가상 데이터로 세 시나리오 표시. 실제 센서·LLM·실행 API 호출 없음 |
| `http://127.0.0.1:8000/health` | 서버 확인 | `status: ok`, `agent_ready: false` |
| `http://127.0.0.1:8000/docs` | API 명세·수동 호출 | FastAPI 문서 |

화면 연습 모드에는 화구 선택 아래, 실행 시작 위에 **화면 연습 시나리오**가 표시된다. 정상 흐름·미인식 후 복구·센서 오류 모두 마지막에는 `uncertain`/`UI_FIXTURE_ONLY`로 종료한다. `서버 연결 없음`은 이 모드의 정상 표시다. 기본 화면에는 연습 시나리오 메뉴가 없다. `refresh=14`는 필수 설정이 아니다.

기본 화면은 조작 완료 알림(`/ack`) 후 관측 상태를 확인하고 같은 조작 ID로 `/step`을 요청한다. 기본 센서 미설정 환경에서는 `sensor_adapter_unconfigured` 근거의 `uncertain`으로 종료하며 다음 실행을 만들 수 있다. 실제 LLM·관측 어댑터의 운영 연결(C-YD-04)과 정상/복구/실물 통합 검증은 남아 있다.

Windows에서는 `.mjs` 응답 형식과 모듈 캐시 문제가 PR #13에서 수정됐다. 수정 전 서버가 실행 중이면 재시작하고 브라우저를 새로고침한다. 현재 실행 안내는 FastAPI가 제공하는 화면을 기준으로 한다.

화면 연습은 화력을 한 단계 올리는 목표만 지원한다. 입력 문장의 화구와 선택한 화구가 다르거나 목표가 다른 경우 조작 안내를 내지 않고 확인을 요청한다. 해당 실행을 취소한 뒤 목표를 고쳐 새로 시작한다.

시연 후 `실행 기록 JSON 저장`을 누르면 현재 run과 이벤트의 파일 저장을 요청하고 같은 JSON 내용을 화면에도 보여준다. 인앱 브라우저에서 다운로드가 제한되면 화면의 내용을 선택해 복사할 수 있다. 파일에는 입력 문장도 포함되므로 공유 전 확인한다. 화면 연습 파일은 `ui_fixture`로 표시되며 실제 실행 증거가 아니다.

화면의 ‘지금 할 일’은 단계별 행동을 크게 보여준다. 필요하면 ‘큰 글씨 켜기’를 누르고, 화면 낭독기와 소리가 겹치면 ‘새 안내 자동 읽기’를 해제한다. 자동 읽기를 꺼도 안내 텍스트와 ‘안내 다시 듣기’는 사용할 수 있다.

실제 API 모드에서는 마지막 상태 확인 시각과 연결 상태를 따로 표시한다. 연결이 끊기거나 조작 완료 요청의 결과를 확인할 수 없으면 기존 화면을 현재 상태로 취급하지 않고 ‘상태 다시 확인’으로 재조회한다.

화면을 새로 열었다면 실제 API 모드의 `기존 실행 다시 확인`에 서버 실행 ID를 입력해 조회할 수 있다. 조회는 `GET /api/runs/{id}`만 사용하며 새 실행을 만들지 않는다. 현재 실행이 진행 중일 때는 다른 ID 조회를 막는다. API 응답 형식이 다르거나 성공 근거가 부족하면 오류 또는 `성공 근거 부족`을 표시한다.

현재 FastAPI는 `frontend/`의 파일을 URL 루트 `/`에 제공한다. `/frontend/`가 아닌 위 주소를 사용한다. 화면은 [실행계약 v0.2](docs/실행계약.md)를 따르며 [Demo 실행 순서](docs/Demo실행.md), [검증 현황](docs/검증결과.md)을 참고한다. 별도 출처의 개발 서버와 연결하는 `?api=...` 방식은 백엔드 CORS 설정이 필요하며 현재 기본 실행 절차에 포함하지 않는다.

```powershell
node --test tests/integration/frontend.test.mjs
```

Node.js 20 이상에서 프런트 계약 검사를 실행한다.

## 제출물 준비

- 발표자료: 고객 문제, Agent 흐름, 구현 범위, 실측 근거, 한계를 각 담당자 증거로 갱신한다.
- 영상: 실제 실행의 입력→안내→Tool/관측→판정/복구를 연속 촬영하고 `source`와 `execution_mode`를 함께 보여준다. UI fixture 영상은 실제 Agent 시연으로 사용하지 않는다.
- 소스 ZIP: README, `frontend/`, 백엔드/검증 코드, 실제 구현한 `skills/<name>/SKILL.md`, 예제 설정, 재현 가능한 실행 방법을 포함한다. 비밀키·캐시는 제외한다.

## API 설정 준비

실제 모델과 테스트용 Mock 센서를 연결해 먼저 개발한다. 초기 제공자/모델 기본값은 OpenAI / gpt-6-luna이며 최종 성능 검증 완료를 뜻하지 않는다.
[.env.example](.env.example)은 설정 형식만 제공한다. C-YD-01에서 저장소 루트 .env 로더와 provider 코드가 병합됐다. 환경변수가 파일보다 우선한다. 현재 API는 설정만으로 실제 LLM 실행으로 전환되지 않으며, 외부 호출을 포함한 Agent 운영 연결·실제 사용량 검증은 C-YD-04에 남아 있다. 서버와 테스트는 API 키 없이 실행할 수 있다.
지원받은 API 예산은 팀 전체 개발과 Agent 실행을 합쳐 20만 원이며, [Agent실행](docs/Agent실행.md)에 설정·검증·사용량 기준을 정리했다.
