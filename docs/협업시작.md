# GitHub 협업 상태

원격: https://github.com/khw04/TouchBack (공개). 사용자의 명시 승인으로 원본 PDF 두 개를 pdf/에 포함한다. 원본은 수정하지 않는다.

## 현재 main 보호 설정 (2026-10-20 API 확인)

- 사용자가 **필수 승인 수 0명**을 유지하도록 명시 승인했다. 과거의 1명 필수 규칙을 대체한다.
- 새 커밋의 기존 승인 취소는 켜져 있고, 마지막 push 작성자 외 승인 필수는 꺼져 있다.
- 관리자에게도 적용, force push/main 삭제 금지, 리뷰 대화 해결 필수.
- squash merge만 허용. 병합된 작업 브랜치 자동 삭제 설정은 main 삭제 금지와 별개다.

동료 검토·지적 사항 확인·관련 검증은 계속 수행한다. 필수 승인 수 0은 모든 미래 PR을 자동 병합하라는 허가가 아니다. 사용자에게 병합 요청을 받은 PR을 대상으로 정확한 최신 커밋과 검사 결과를 확인한다. 보호 설정을 변경할 때는 별도 요청과 실제 API 확인이 필요하다.

기존의 초기 세팅 예외·일시 해제/복원 기록은 당시 이력이다. 현재 정책과 혼동하지 않는다. 각자 별도 복제본과 작업 브랜치를 사용하고, 담당·현재 의존성은 작업현황을 따른다.
