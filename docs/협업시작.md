# GitHub 협업 상태

원격: https://github.com/khw04/TouchBack (공개). 사용자의 명시 승인으로 원본 PDF 두 개를 pdf/에 포함한다.
빈 원격 main은 GitHub 자동 초기화 README를 기준으로 만들었다. 초기 문서 PR #1은 사용자가 지정한 초기 세팅 예외로 병합했다. 이후 리뷰 예외는 사용자가 명시한 해당 PR에만 적용하고 보호 설정을 복원한다.

## main 보호 기준

- PR의 승인 리뷰 최소 1명, 작성자 자기 승인 불가.
- 변경이 추가되면 이전 승인 취소, 마지막 push 작성자 외 승인 필요.
- 관리자에게도 적용, force push/삭제 금지, 리뷰 대화 해결 필수.
- squash merge만 허용. 구현 전 빈 CI를 required check로 만들지 않는다.

실제 적용 여부는 GitHub API 재조회로 확인한다. 설정 오류가 있으면 완료했다고 보고하지 않는다.
팀원 GitHub 계정은 아직 제공되지 않아 초대/리뷰어 지정은 미완료다. 리뷰어는 저장소 write 권한을 받아야 승인 요건에 포함된다.
각자 별도 복제본에서 작업하고 역할분담의 다음 티켓을 따른다. 현재 문서 PR은 첫 동료 승인 뒤 병합한다.
