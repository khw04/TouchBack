## 2026-10-13 Windows 화면 모듈 응답 수정

로컬 FastAPI 서버가 .mjs를 text/plain으로 제공해 브라우저 모듈 실행이 차단되는 문제를 재현했다. .mjs를 text/javascript로 명시 등록해 운영체제 MIME 설정 영향을 제거했다. 화면 모듈 5개 응답의 Content-Type 회귀 검사를 포함한 백엔드 테스트 213개 및 diff 검사 통과. 실행 중 서버는 재시작이 필요하다. 이전 MIME 응답 캐시로 화면 초기화가 계속 실패하는 문제를 실제 브라우저에서 재현하고, 진입 스크립트와 모든 모듈 의존성 URL을 v14로 갱신했다. 이후 브라우저에서 화면 연습 시나리오 표시 및 실행 시작 → 조작 완료 알림 → UI_FIXTURE_ONLY 확인 불가 종료를 확인했다. 프런트 회귀 테스트 23개 통과. 실제 음성 출력은 미검증이다. 기존 정적 파일 HTTP 200 검사만으로는 브라우저 모듈 실행을 검증하지 못했다.

## 2026-10-13 목표·관측·취소 안전 수정

수정 전 현재 코드로 음악 시작 요청의 + 안내, 문장/선택 화구 충돌 무시, Agent의 두 단계→한 단계 축소, ack 후 이틀이 지나도 observing 유지, uncertain 후 cancel의 stopped 덮어쓰기를 재현했다.

- API/Agent 공통 결정론적 목표 검증 및 fixture와 공유한 31개 입력 사례로 정상 좌/우·화구 미명시/충돌·부정·다단계·복합·무관 요청을 검사했다.
- 조작 ID별 관측 한 번 처리, 중복 ack/step/폴링, 재시도 ack 후 이전 step, 취소 경쟁, 관측/복구 예외, 시간 초과, 요청 작업 취소와 늦은 결과 폐기, 종료 결과 보존/잠금 해제를 검사했다.
- 백엔드 전체 pytest 256개 통과(기존 의존성/상수 deprecation 경고 4개). Mock 성공은 합성 관측 검사이며 실물 성공이 아니다.
- 실제 FastAPI 8001 서버와 인앱 브라우저에서 정상 오른쪽/왼쪽 시작→완료 알림→step→uncertain 종료 및 다음 실행 생성, 음악 요청/화구 충돌의 명확화와 조작 안내 차단을 확인했다. 미설정 센서는 sensor_adapter_unconfigured, 근거 ID 없음이다. 기존 8000 서버는 변경하지 않았다.
- 프런트 `node --test tests/integration/frontend.test.mjs` 28개 통과. fixture 종료/반복 취소 보존, 요청/본문 무응답의 제한 및 AbortSignal도 확인했다.
- Python compileall, 프런트 모듈/테스트 node --check, git diff --check 통과. LSP 기능은 제공되지 않았으며 Ruff/Pyright/BasedPyright/Flake8/Pylint/pycodestyle이 설치되지 않아 해당 정적 분석은 수행하지 못했다.

외부 LLM, 실제 ESP32/인덕션, 음성 출력, 실제 드라이버의 읽기 중단은 미검증이다. 관측/복구 제한은 서버 종료를 보장하지만 이미 진행 중인 동기 드라이버 읽기를 강제로 죽이지 않는다. 실제 LLM 운영 연결은 C-YD-04, 실측 보정과 정상/복구 live 통합은 기존 담당 작업으로 남는다.

## 2026-10-18 PR #17 JSON 파서 후속 수정

이전 리뷰의 별도 후속 항목이던 깊은 JSON 입력 처리를 재현 후 수정했다. 8192바이트 이하의 깊이 3500/4000 배열에서 decoder의 RecursionError와 다음 정상 프레임 유실, Replay의 재귀 예외가 수정 전 발생했다. Serial은 parse_error 기록 후 다음 프레임을 계속 저장하되 오류 품질을 보존하고, Replay는 원문 없이 ValueError로 거부한다. 신규 회귀 6개 포함 이 브랜치 backend 281 / frontend 28 통과. 파서·수집 검사 47개, compileall/diff 검사 통과. 실제 하드웨어·외부 모델·미설치 LSP/lint는 미검증이다.
