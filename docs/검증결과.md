## 2026-10-13 Windows 화면 모듈 응답 수정

로컬 FastAPI 서버가 .mjs를 text/plain으로 제공해 브라우저 모듈 실행이 차단되는 문제를 재현했다. .mjs를 text/javascript로 명시 등록해 운영체제 MIME 설정 영향을 제거했다. 화면 모듈 5개 응답의 Content-Type 회귀 검사를 포함한 백엔드 테스트 213개 및 diff 검사 통과. 실행 중 서버는 재시작이 필요하다. 이전 MIME 응답 캐시로 화면 초기화가 계속 실패하는 문제를 실제 브라우저에서 재현하고, 진입 스크립트와 모든 모듈 의존성 URL을 v14로 갱신했다. 이후 브라우저에서 화면 연습 시나리오 표시 및 실행 시작 → 조작 완료 알림 → UI_FIXTURE_ONLY 확인 불가 종료를 확인했다. 프런트 회귀 테스트 23개 통과. 실제 음성 출력은 미검증이다. 기존 정적 파일 HTTP 200 검사만으로는 브라우저 모듈 실행을 검증하지 못했다.
