# 제안서 원안과 본선 목표 추적

근거: [TouchBack 제안서](../pdf/20225247_임민혁.pdf) 6~11쪽, [평가 안내](../pdf/%28첨부%292차%20과제%20제출%20및%20평가%20안내%20.pdf) 1~2쪽.
P0/P1/P2는 개발 순서다. P0 완료는 원안 전체 완료나 대회 평가 충족을 뜻하지 않는다.
아래는 제출했던 제안서의 목표이며 평가 안내가 모든 기능 구현을 별도로 의무화했다는 뜻은 아니다.
최종 범위를 조정하면 누락 기능·근거·효과의 한계를 발표/README에 명시한다. 자동으로 미래 확장으로 돌리지 않는다.

현재 실측 검증은 모두 미완료다. C-KH-05의 보정 후보/화구별 상태·재동기화/재보정은 Mock 준비 코드만 검증했으며 다기종·냄비·확장 신호 특징·잔열 등 원안 목표 완료를 뜻하지 않는다. 98%, 정확 단계 95%(±1 99%), 지연 ≤1초, 냄비 미인식 ≤2초,
재동기화/기준 신호 이상 감지 95%는 제안서의 설계 목표다. 소규모 내부 반복 검사와 같은 의미가 아니다.
제안서 10/28 일정은 평가 안내에서 마감으로 재확인되지 않았다.

## 원문에 없는 구현 선택

Python/FastAPI, 정적 웹, Arduino/USB, JSON v0.2, 시도/대기 횟수, 내부 10회·5회 측정은 개발 기본값이다.
PR 팀원 승인과 이름별 담당은 사용자의 협업 요청이다. 원문 근거로 인용하지 않는다.
ThinQ/타 가전/공공 보급 등은 원안에서도 확장 방향이며 현재 연동 기능이 아니다.
