# 센서 없는 시연의 관측 범위

2026-10-19 사용자 승인: 실물 센서 연결/실측 없이, 구매한 부품으로 얻을 수 있는 종류의 관측만 Mock으로 생성한다. 정확도/설치 가능성의 실물 검증을 요구하지 않고 소프트웨어를 진행하되, 합성 성능을 실제 센서 성능으로 보고하지 않는다.

## 센서 종류와 모델 가정

가상 코일은 채널당 200Hz, 두 채널 합계 400회/초의 처리된 신호를 모델링한다. ADS1115의 최대 변환률 860SPS 이내로 둔 개발 가정이며 실측/확정 수집 설정이 아니다. 고주파 원시 자기장 파형을 ADC로 직접 분석한다고 가정하지 않는다. sample_count는 이 수집률과 관측 시간에 맞춘다. 부품의 최대 변환률은 [TI 데이터시트](https://www.ti.com/lit/ds/symlink/ads1115.pdf)를 참고한다. 실제 회로 대역폭·정류/필터·포화·입력 보호·채널 간섭 검증은 이 Mock 구현과 별도다.

합성 단계 프로필은 source=mock 개발 표본으로만 생성한다. 내부 가상 화력·실제 누른 버튼·시나리오·프로필 학습 정답은 Agent 입력에 제공하지 않는다. 센서 요약·품질·시간·관측 ID로 판단하며 양쪽 중 하나라도 누락/불량/미보정/낡음이면 성공/교정 원인을 단정하지 않는다. double_input은 입력의 중복 반응을 흉내 낸 조건이고 duplicate는 동일 관측의 중복 전송이다. 비프음 두 번만으로 실제 터치 두 번이라고 말하지 않는다.

## 완료 범위와 별도 작업

이 문서 범위는 가상 시연의 기능 구현이다. 실제 LLM 키로 외부 호출/사용량 검증, 실제 마이크·음성 서비스 인식, 스피커·화면 낭독기 사용자 평가, 실물 센서/인덕션 정확도는 별도다. 코드와 모의 회귀 통과를 해당 검증 완료로 보고하지 않는다. IR 잔열·진동·레시피/개인화·모든 인덕션 버튼을 이 범위 완료에 합산하지 않는다.
