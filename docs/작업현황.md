## 현재 검증 근거

- 변경 전 main: 백엔드 609개, 프런트 99개 통과.
- 이번 보완: 지연 성공 뒤 stop과 초기 계획 취소 후 사용량 보존 회귀를 추가했다. 전체 백엔드 614개·프런트 100개 통과, 기존 Starlette deprecation warning 6개가 있다. 수정 전 코드에서는 신규 회귀 3개가 실패하고 수정 후 통과함을 확인했다. Python compileall·Node 구문·SVG XML·진입 문서 링크·git diff --check를 확인했다. Ruff/Pylint/Pyright/pylsp는 설치되지 않아 실행하지 못했다.
- 실제 Claude+Mock 정상 완료·다른 화구 중단·미인식 검토/1회 재안내 후 완료·센서 오류 중단 개발 호출은 [Agent 판단](Agent판단.md)에 기록했다. 4개 사례의 개발 증거이며 통계적 성능이 아니다.
- 이번 실제 FastAPI+브라우저: mock_llm 정상 시작→가상 버튼→모의 관측→목표 확인, 다음 실행 생성 및 취소를 확인했고 콘솔 경고/오류는 없었다. 부품/신호 SVG도 브라우저에서 확인했다. 지연 성공 후 stop 및 초기 계획 취소 경쟁은 오프라인 provider 회귀로 검증했다.
- 실제 회로/센서·물리 인덕션 정확도·실제 마이크 인식·대상 사용자 평가는 미검증이다. 이번 유지보수에서는 유료 API 호출을 추가하지 않는다.
