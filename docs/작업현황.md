## 문서에 반영된 결정과 실제 진행 구분

2026-10-08: 구매 구성 결정과 멘토 피드백을 문서에 반영했다. 주문/배송/수령·실측과 코드 구현은 확인되지 않아 해당 티켓을 완료로 바꾸지 않았다.
Agent P0는 C-KH-01 → 최소 API/Mock/검증 → 실제 LLM 연결·복구 → 세 경로 Demo 순서로 진행하며 실물 통합은 병렬로 준비한다.
LLM 초기 기본값은 Luna이고 API 키 발급/접근은 미확인이다. 실제 LLM 검증이 막히면 계약·Mock·UI 작업은 계속하고 실제 Agent 검증은 자격증명 대기로 구분한다.
