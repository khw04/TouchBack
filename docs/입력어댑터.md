# Serial/Replay 입력 어댑터 (C-KH-04)

## 구현 범위

SerialAdapter는 pyserial의 제한된 read timeout으로 UTF-8 JSON Lines를 읽는다. 장치에 제어 명령을 쓰지 않는다.
JsonLinesDecoder는 분할/다중 줄, LF 포함 최대 8192바이트, UTF-8/JSON/버전/필드 검사와 중복 JSON 키 거부를 처리한다. 잘못된 원문/포트 상세를 오류 로그에 담지 않는다.
InputBuffer는 최신 관측 256개, 중복 확인 256개, 오류 코드 100개를 보관한다. 동일 관측 중복을 제외하고 충돌/순번 역행/출처·장치 불일치를 오류로 처리한다.
부팅 세션 변경은 이전 기준/매핑을 폐기하고 오류 상태로 표시한다. 자동으로 이전 실행을 계속하지 않는다. 재연결은 새 SerialAdapter를 열어 새 기준을 수집한다.

## 사용 (backend 폴더의 Python)

```python
from app.adapters.serial_input import SerialAdapter

# 포트/전송 속도는 실제 펌웨어 설정을 확인한 뒤 지정한다.
with SerialAdapter.open("COM3", baudrate=115200, expected_device_id="esp32-01") as adapter:
    baseline = adapter.read_baseline("right")
    quality = adapter.check_sensor_integrity()
```

`await_touch_result`는 Mock과 동일한 run_id/action_id/zone_id/window_start_ms/window_end_ms/timeout_ms를 받는다. Serial은 실제 호스트 단조 시간을 사용하고 Replay는 원본 기록의 수신 단조 시간을 가상 시간으로 사용한다. 같은 실행에서 서로 다른 시계를 섞지 않는다.
Serial은 취소 검사 함수를 추가로 받을 수 있다. 취소하면 버퍼를 폐기하고 빈 배열을 반환한다. 재연결/명시적 재동기화 전 오류는 유지한다.
read timeout은 최대 100ms로 제한한다. 대기/취소 종료는 한 번의 read timeout만큼 늦어질 수 있다. FastAPI 비동기 처리에서 호출하려면 작업 스레드로 분리해야 한다. 스레드 공유/다중 실행 제어는 Agent 담당 영역이다.
수집 창 경계의 관측과 매핑 없는 관측은 Verifier에 전달해 불확실을 설명하게 한다. 이미 전달한 관측은 한 번만 반환하므로 호출자가 근거를 보관한다.

## 기록 재생

```python
from app.adapters.replay import ReplayAdapter

adapter = ReplayAdapter.from_file("observations.jsonl")
baseline = adapter.read_baseline("right")
```

파일은 호스트 Observation v0.2 하나 + LF 형식이다. 수신 단조 시간이 역행하거나 형식/길이가 잘못되면 로딩을 중단한다. 잘못된 줄을 조용히 건너뛰지 않는다. 같은 호스트 시계의 한 기록을 사용한다.
원본은 수정하지 않고 반환 출처를 replay로 바꾼다. 원본 출처는 recorded_sources에 별도로 보존한다. 이전 run/action/검증된 시계 표시는 재사용하지 않는다.
Replay는 입력 생성기가 아닌 기존 기록의 재생이다. 실제 장비 기록이 아직 없으므로 모의 기록으로만 검증했다.

## 시간과 성공 판정 제한

5개 연속 관측의 수신-장치 종료 차이 중앙값으로 표시용 매핑을 추정한다. 전송 지연이 포함되므로 live/replay 모두 clock_quality=unverified다. 실측 시계 허용 오차 검증 없이 verified로 올리지 않는다.
최신 관측은 신선함을 보장하지 않으며 Verifier의 품질/시간/보정 검사가 필요하다. 기존 Mock 보정으로 live/replay 성공 판정을 하지 않는다.
