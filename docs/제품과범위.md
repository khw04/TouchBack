# 제품과 구현 범위

## 고객 문제와 동작

시각장애인·저시력 고령자는 평면 터치 버튼의 위치뿐 아니라 조작이 인식되었는지와 실제 가열 상태를 확인하기 어렵다.
TouchBack은 외부 센서로 조작 이후 변화를 관측하고 사용자의 목표와 비교해 음성 안내와 교정 행동을 제공한다.
기존 인덕션 내부를 개조하지 않으며 사용자가 터치한다. 음성만으로 자동 가열을 실행하는 장치는 현재 범위에 없다.

## 우선순위와 첫 구현 범위

P0는 개발 시작 단계다. P1/P2로 분류한 원안 기능도 본선 목표에서 삭제하지 않는다.
[본선원안목표](본선원안목표.md)에 원문 쪽수·담당·증거를 연결했다. 축소 제출 시 차이를 명시한다.

| 우선순위 | 내용 | 조건 |
|---|---|---|
| P0 | 한 기종·한 화구, 화력 증가 안내·검증, 미인식 후보의 교정·재검증 | 첫 구현 범위; 실측 성능 확인 필요 |
| P0 | 모의/실제 어댑터, 관측 유효성, 실행 로그, 두 핵심 Skill, 음성 안내/재청취 | 코드 미구현 |
| P1 | 두 화구, 중복/다른 화구 후보, 상태 재동기화·센서 재보정 | 실측으로 판별 가능한 경우 |
| P2 | IR 잔열, 기종 자가보정, 타이머/레시피, 개인화·진동·음성 입력 | P0 이후 진행할 원안 목표 |
| 미래 | 다른 가전과 ThinQ 연계 | 제공 API와 권한 확인부터 필요 |

원안은 두 화구와 여러 Skill을 제안했다. P0 축소는 완결된 Agent 경로를 먼저 구현하기 위한 제안이며 현재 구현 시작 기준으로 사용한다. 사용자 직접 선택과 기본 구현 결정을 구분해 기록한다.
'한 단계 증가'는 사용자 목표다. 실측 P0는 출력 변화 확인부터 시작하고 정확 단계 확인은 별도 검증한다. [판정기준](판정기준.md)에 따라 확인 수준을 표시한다.

## 성공 기준

Agent가 사용자 목표에 맞는 Tool을 선택하고 관측으로 판단하며 실패/불확실에서 다음 행동을 바꾼다.
센서 출력과 분리된 고정 성공 화면으로 Demo를 대체하지 않는다.
실측 가능한 범위 안에서만 성공을 확인한다. 확인 불가능한 상태는 추가 관측 또는 사용자 확인을 요청한다.
