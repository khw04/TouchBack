# 저비용 센서 선정과 실측

결정: 저렴한 센서를 구매할 방향. 미정: 모델·수량·총액·인덕션 확보 방식.
여기에는 최신 가격이나 검증하지 않은 부품 호환성을 기재하지 않는다. 구매 전 실제 판매 사양·가격을 확인한다.

## 선택할 항목

| 항목 | 후보 방향 | 선택 근거/확인 |
|---|---|---|
| 자기장 | 외부 픽업 코일 + 신호 처리 회로 | 유도 신호 크기·대역·방향·설치 반복성, ESP32 입력 보호 |
| 소리 | 마이크 모듈 | 인덕션 비프와 팬/주변 소리 구분, 아날로그/디지털 입력 |
| 수집 | ESP32 계열 | 보유 장비 우선, 입력 채널·ADC/통신·전원 검토 |
| 주변부 | AFE/배선/전원/고정 부품 | 센서 단가 외 전체 비용과 설치 안정성 |
| 잔열 | IR 온도 센서 | P2, 측정 위치·방사율·거리와 정확도 검증 후 |

전자팀이 부품 사양을 확인한다. 코일을 ESP32에 바로 연결해도 된다고 가정하지 않는다.
온도 센서 없이 잔열 안전 기능을 실측 구현했다고 주장하지 않는다.

## 확보와 측정

실제 인덕션은 구매·대여·기존 시설 활용 중 선택한다. 모의 개발은 실물 없이 가능하지만 실제 센서 검증에는 실물이 필요하다.
P0는 한 기종·한 화구로 시작한다. 모델, 냄비, 설치 사진/위치, 출력 조건, 보정 버전을 기록한다.
OFF/유지/증가 반복, 비프음 미감지, 저출력 주기, 팬 소음, 다른 화구 간섭을 측정한다.
원시 기록 → 요약 관측 → 판정 결과를 연결하고 성공한 샘플만 선택하지 않는다. [실측평가절차](실측평가절차.md)의 독립 정답과 개발/평가 분리를 따른다.

## 선정 통과 조건

팀 예산 안에서 안전한 외부 설치·수집이 가능하고, P0 목표에 필요한 변화를 반복 관측할 수 있어야 한다.
구분이 어려우면 추가 부품 구매 전에 설치/AFE/관측 시간창을 개선하고 범위를 재검토한다.
검증 전 부품의 정확도·한 단계 분해능을 약속하지 않는다.
