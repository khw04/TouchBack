# 구매 확정 부품과 실측

2026-10-08: 사용자가 견적서.xlsx의 구성 그대로 구매하기로 확정했다. 아래는 장바구니목록 A2:H12의 상품명·수량·금액을 옮긴 기록이다. 견적서 원본과 주문 계정 정보는 저장소에 추가하지 않는다.
구매 결정은 완료됐지만 주문 접수·배송·수령·회로 검증·실측 완료는 아직 확인되지 않았다. 기종과 인덕션 확보 방식도 미정이다.

## 담당자 다음 작업

- 임민혁: 구매 후보를 다시 선정하기보다 확정 부품 사양과 보유 장비를 확인하고 회로·설치·측정 절차를 정리한다. ESP32, 저항, 배선, 전원, 고정 부품의 보유/추가 필요 여부와 인덕션 접근 조건을 확인한다.
- 차우진: INMP441의 I2S와 ADS1115의 I2C 수집 경계를 설계하고, 실물 없이도 USB JSON Lines의 모의 출력부터 준비한다. 실제 보드 확인 전 핀맵은 확정하지 않는다.
- 구매한 IR 센서와 진동 모듈은 후속 기능에 사용한다. 도착했다는 이유만으로 Agent P0에 모든 기능을 추가하지 않는다.

## 회로·호환성 확인

픽업 코일 신호를 ESP32에 바로 연결하지 않는다. 증폭·정류·필터·입력 보호와 실제 전압 범위를 전자팀이 확인한다.
ADS1115에는 고주파 원시 파형을 직접 분석하는 역할을 맡기지 않고 처리된 신호의 수집을 계획한다. LM358과 1N5819가 실제 코일 신호를 충분히 처리하는지는 실측으로 검증한다.
INMP441은 아날로그 ADC 입력이 아닌 I2S 디지털 마이크다. IR/진동 모듈의 전원과 신호 전압, 구동 방식은 판매 사양과 보드 확인 뒤 배선한다.
멀티미터는 회로 점검용이며 고주파 파형 검증을 대신하지 않는다. 필요하면 학교 측정 장비 사용 가능 여부를 확인한다.

## Agent 중심의 하드웨어 범위

멘토 피드백에 따라 하드웨어는 Agent의 핵심 행동을 검증할 관측 제공에 집중한다. 자기장 변화·비프음·센서 품질을 같은 관측 계약으로 제공하는 최소 경로부터 완성한다.
컴공팀의 실제 LLM + MockAdapter 개발은 부품 배송이나 실측 완료를 기다리지 않는다. 모의 입력만으로 공식 본선 요건을 충족한다고 해석하지 않는다.

## 확보와 측정

실제 인덕션은 구매·대여·기존 시설 활용 중 선택한다. 실측에는 접근 가능한 실물이 필요하다.
P0는 한 기종·한 화구로 시작하고 기종·냄비·설치 위치·출력 조건·보정 버전을 기록한다.
OFF/유지/증가, 비프음 미감지, 저출력 주기, 팬 소음, 다른 화구 간섭을 측정한다.
원시 기록 → 요약 관측 → 판정 결과를 연결한다. [실측평가절차](실측평가절차.md)의 독립 정답과 개발/평가 분리를 따른다.
구매 확정으로 정확도나 한 단계 분해능을 보장하지 않는다. 구분이 어려우면 설치/회로/시간창을 검토하고 관측 가능한 범위를 기록한다.
