## BoothLock 참고

사용자가 지정한 [hong0527/boothlock-server](https://github.com/hong0527/boothlock-server)의 문서 체계와 협업 방식을 참고했다.
검토 대상은 루트 README/CLAUDE/CONTRIBUTING, PR 템플릿, 빌드 설정, API/DB 명세의 변경 이력·미정 항목, 배포 운영 문서다.
전체 소스 코드 감사나 외부 Notion 검토를 했다는 의미는 아니다.

| 참고 방식 | TouchBack 적용 |
|---|---|
| 공통 AI 진입점과 기여 규칙 | AGENTS/CLAUDE는 공통프롬프트와 CONTRIBUTING을 가리킴 |
| 명세의 버전·근거·미정 목록 | 관측 계약 v0.2, 결정기록, 구현 상태 구분 |
| 담당 경계와 공동 변경 규칙 | 전자/컴공 관측 계약과 역할 표 |
| PR 목적·근거·검증·리뷰 초점 | PR 템플릿 + 팀원 필수 승인 |
| 실제 운영/검증 기록 | 구현 후 재현 실행·실측 근거 기록 |

BoothLock의 도메인 규칙, Java/React 스택, 사람별 소유권, 분량 제한, 리뷰 기한은 그대로 가져오지 않았다.
TouchBack 코드가 없으므로 작동하지 않는 CI나 실행 명령도 만들지 않았다.

## 원안과 현재 범위의 최종 대조

[본선원안목표](본선원안목표.md)에서 연기한 원안 기능과 새 구현 선택을 구분한다. P0는 첫 내부 완료 단계다. 평가 안내는 실제 구현한 핵심 기능을 중점 평가하며, 제안서 목표 전체 달성을 완료했다고 허위로 표시하지 않는다.
