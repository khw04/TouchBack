# 실측 정답과 평가 절차

담당: 임민혁 측정 조건/정답 기록, 차우진 데이터 수집, 권희원 보정/집계, 김민찬 증거 묶음.
AI에 정답을 전달하지 않는다. 측정자는 장비 설명서와 실제 표시로 조작 전후 단계를 확인한다.

## 준비와 정답

trial_id, 기종, 화구, 냄비, 설치 사진/위치, 회로/펌웨어/보정 버전, 요청 목표를 기록한다.
인덕션의 표시 단계를 별도 사람 또는 녹화로 읽어 before_level/after_level/action_time을 기록한다.
시각 확인이 불가능한 기종이면 exact_step 평가를 하지 않고 독립 측정 수단부터 마련한다.
표시 단계 차이는 '표시 단계 변경'의 정답이지 소비전력/실제 열량의 직접 측정값이 아니다.
Agent 안내의 action_id와 평가 trial_id를 평가 파일에서 연결한다. 정답 파일은 어댑터/Agent가 읽지 못하게 분리한다.

## 첫 측정 횟수

개발용: OFF/유지/한 단계 증가 각 10회로 관측 가능성과 시간창을 탐색한다.
평가용: 개발 측정과 별도로 정상 +1 / 터치하지 않음 / 가능한 범위의 중복 +2 각 10회.
최대 단계 등 +1 불가능한 조건은 별도 기록하고 정상 +1의 분모에 섞지 않는다.
센서 이상·지연·중복 전송은 실제 실험 가능한 항목과 주입 실험을 구분해 각각 5회 수행한다.
위 횟수는 첫 통합 확인 기준이며 제안서 정확도 목표를 통계적으로 입증하는 표본 수는 아니다.

## 저장과 집계

평가 파일: trial_id/action_id/전후 표시 단계/관측 시간/보정/예상 결과/실제 판정/판정 수준/지연/제외 사유.
실패·불확실도 포함한다. 전송 실패를 조용히 제외하지 않는다. 잘못된 조건의 제외는 사유와 별도 수를 공개한다.
exact_step 목표 충족률, 확인 범위별 건수, 오성공(실패인데 성공), 불확실률, 지연을 별도 집계한다.
센서 출력으로 만든 정답과 센서 출력 판정을 비교하지 않는다. 독립 정답이 없는 항목은 '평가 불가'다.
반복 측정 전 baseline과 표시 상태를 재확인한다. 안전한 실험 조건은 현장 담당자가 확보하고 실제 센서 사양에 맞춰 실행한다.

## 원안의 안전·사용자 평가 조건 — 제안서 11쪽

실물 시연은 소량의 물과 제한된 출력 조건으로 진행한다. 뜨거운 냄비/상판 취급 시 안전장비를 착용한다.
실험 담당자가 기종 설명서와 실험 장소의 조건을 확인하고 위험·센서 이상 시 실험을 중단한다.
사용자 평가 전에 목적·절차·한계·중단 가능성을 설명하고 사전 동의를 받는다.
평가 파일/발표에는 참가자 이름·연락처를 넣지 않고 익명 식별자를 쓴다. 원시 음성·영상의 저장/공유 범위도 동의 내용에 맞춘다.
TouchBack은 조리 접근성 보조기기이며 모든 안전을 보장하는 장치로 설명하지 않는다.
잔열/출력 종료 기능이 미구현이면 그 한계를 실험·Demo 시작 전에 알린다.
